# Support and feedback

Use this repository for AI Chat Backup documentation, bug reports, and feature requests.

## Before requesting help

1. Update AI Chat Backup from the Chrome Web Store.
2. Review [Installation](docs/INSTALLATION.md) and [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Search [existing issues](https://github.com/lnmput/chatgpt-to-notion/issues) for the same platform or error.
4. Remove private content from screenshots and examples.

## Report a bug

Use the [bug report form](https://github.com/lnmput/chatgpt-to-notion/issues/new?template=bug_report.yml) for:

- Missing or incomplete ChatGPT exports
- Broken formatting in Markdown
- Obsidian folder problems
- Notion authorization or sync errors
- AI platform interface compatibility problems
- Batch export failures

Include the extension version, Chrome version, operating system, AI platform, reproduction steps, and expected result.

## Request a feature

Use the [feature request form](https://github.com/lnmput/chatgpt-to-notion/issues/new?template=feature_request.yml) to suggest:

- A new AI chat platform
- A new export format
- Markdown or YAML improvements
- Notion workflow improvements
- Accessibility improvements

Explain the problem and desired outcome, not only the proposed implementation.

## Privacy when reporting problems

GitHub issues are public. Do not include:

- Full private AI conversations
- Notion provider tokens or database credentials
- Browser cookies or session data
- Personal email addresses or account identifiers
- Confidential screenshots

Create a minimal, sanitized example whenever possible.

## Security reports

Do not open a public issue for a vulnerability or exposed credential. Follow [SECURITY.md](SECURITY.md) instead.

## Chrome Web Store

Install or update the extension from the [official Chrome Web Store listing](https://chromewebstore.google.com/detail/chatgpt-ai-chat-backup-ma/oedpeddiacomhhfieanenlmdghkolgng).
