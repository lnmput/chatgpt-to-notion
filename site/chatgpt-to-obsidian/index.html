AI Chat Backup / ChatGPT to Obsidian

Local knowledge base guide

Save ChatGPT directly to Obsidian.

Choose a folder inside your Obsidian vault once. When permission is available, AI Chat Backup writes future Markdown exports directly into that folder instead of the browser downloads directory.

Install AI Chat Backup

Choose your Obsidian export folder

  1. Open the extension settings.
  2. Open the Export section.
  3. Under Markdown Export Folder, select Choose Folder.
  4. Choose an existing folder inside the active Obsidian vault.
  5. Approve write access when Chrome requests it.

Export and find the note

Open a supported AI conversation, wait for the response to finish, and select Export Chat. Obsidian detects the new Markdown file automatically. If it does not appear, refresh the file explorer and confirm that the configured folder belongs to the open vault.

Organize AI conversation notes

Enable YAML front matter to add title, date, source, and custom properties. Use a dedicated folder and link exported chats to the projects where they matter. Selective exports produce a more useful vault than copying every conversation.

Fix folder permission problems

Chrome may ask for access again after a permission reset, folder move, or rename. Return to Export settings and choose the folder again. If direct folder access is unavailable, the extension falls back to the browser downloads folder.

Notion is optional. Obsidian and local Markdown exports do not require a Notion connection.
