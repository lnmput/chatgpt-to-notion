AI Chat Backup / ChatGPT to Obsidian

Local knowledge base guide

Save ChatGPT conversations directly to Obsidian.

Choose a folder inside your Obsidian vault and let AI Chat Backup write future conversation exports there as Markdown notes.

Install AI Chat Backup

Choose your Obsidian export folder

  1. Open the extension settings.
  2. Open the Export section.
  3. Under Markdown Export Folder, select Choose Folder.
  4. Choose an existing folder inside the active Obsidian vault.
  5. Approve write access when Chrome requests it.

Export and find the note

Open a ChatGPT or other supported AI conversation, select the export action, then return to Obsidian. Obsidian detects standard Markdown files automatically. If the note does not appear, refresh the file explorer or confirm that the selected folder belongs to the open vault.

Organize AI conversation notes

Use a dedicated folder, predictable YAML properties, and links to related project notes. Avoid copying every conversation into the vault. Export the chats that contain decisions, reusable explanations, research, or source material you expect to revisit.

Fix folder permission problems

Chrome may ask for access again after a browser restart, permission reset, folder move, or rename. Return to extension settings and choose the folder again. Confirm that the destination still exists and that your operating system allows Chrome to write to it.

Notion is optional. Obsidian and local Markdown exports do not require a Notion connection.
