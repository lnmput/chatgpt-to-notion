AI Chat Backup / Gemini image download

Generated image guide

Bulk download Gemini generated images.

On a Gemini chat page, AI Chat Backup first tries to use Gemini's own full-size image download controls, captures the original image responses, and packages the captured files into a local ZIP archive.

Install AI Chat Backup

Open a supported Gemini chat

The image download button appears when the current tab is detected as a Gemini chat page. Notion authorization is not required for this action.

  1. Open the Gemini conversation on gemini.google.com.
  2. Wait until the generated images are visible and fully loaded.
  3. Open AI Chat Backup from the Chrome toolbar.
  4. Use the image-download icon or its tooltip label, Download generated images.

How Gemini images are captured

For Gemini, AI Chat Backup runs the image downloader in the page context so it can interact with Gemini's native full-size download buttons. It triggers those buttons, captures image responses or Blob URLs created by the page, and then builds a ZIP archive named like gemini-original-images-<timestamp>.zip.

Fallback scanning

If Gemini's original-image controls are not found, the extension falls back to scanning the page for generated image elements. It checks image tags and Gemini image components, looks for Google image hosts or Blob URLs, ignores user prompts and avatars, deduplicates sources, and saves the detected files into a ZIP archive with a gemini-<conversation-id> prefix.

The native Gemini path is preferred. It is designed to capture the original full-size files instead of only the rendered preview when Gemini exposes a full-size download control.

What the popup reports

The popup starts with Preparing image downloads.... When the process finishes, it reports how many images were downloaded. If some files cannot be captured or fetched, it shows a partial-download warning instead of treating the entire batch as successful.

If no images are found

  • Confirm you are on a Gemini chat page with generated images, not a blank Gemini start page.
  • Wait for Gemini's image cards and download controls to finish rendering.
  • Refresh Gemini and reopen the extension if the button is not available.
  • If Gemini no longer exposes the original image source or download control, the extension may not be able to recover that file.

Keep text context separately

Use Gemini Markdown export or Notion sync for the conversation text, then keep the generated-image ZIP beside that exported note. The image downloader is focused on visual assets; text export is handled by the regular conversation export flow.
