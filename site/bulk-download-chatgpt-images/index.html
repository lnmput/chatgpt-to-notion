AI Chat Backup / ChatGPT image download

Generated image guide

Bulk download ChatGPT generated images.

On a ChatGPT conversation page, AI Chat Backup can scan the visible conversation for generated image sources, fetch the image files with the active browser session, and save them into a local ZIP archive.

Install AI Chat Backup

Open a supported ChatGPT page

The image download button appears when the current tab is a ChatGPT conversation page. It is available whether or not you have connected Notion, because generated image downloads are handled as local browser downloads.

  1. Open the ChatGPT conversation that contains generated images.
  2. Wait for the images to finish loading in the page.
  3. Open AI Chat Backup from the Chrome toolbar.
  4. Use the image-download icon or its tooltip label, Download generated images.

What the extension collects

AI Chat Backup scans the conversation area for image elements that look like assistant-generated images. It excludes user-uploaded images, avatars, favicons, extension images, and tiny layout artifacts. It deduplicates repeated image URLs before creating the archive.

What gets downloaded

The extension fetches each detected image using the active ChatGPT browser session and creates a ZIP file. ChatGPT archives use a generated filename prefix such as gpt-<conversation-id>.zip, and images inside the archive are numbered with their detected file type, such as PNG, WebP, GIF, or JPG.

Keep the ChatGPT tab open until the toast finishes. The popup reports Preparing image downloads..., then shows whether images were downloaded, partially downloaded, or not found.

If no images are found

  • Confirm you are on a specific ChatGPT conversation, not only the ChatGPT home page.
  • Wait until generated images are visible in the conversation.
  • Refresh the page if ChatGPT has not rendered the image elements yet.
  • If the image source no longer loads in ChatGPT, the extension cannot recover the original file.

Use with Markdown and Notion

Markdown export and Notion sync preserve the conversation record. Generated image files are downloaded separately because their source URLs can be temporary or session-bound. Keep the ZIP archive next to the exported Markdown file when you want both the prompt context and the visual assets.
