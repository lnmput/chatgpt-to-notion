# Security policy

## Report a vulnerability privately

Do not disclose security vulnerabilities, authentication tokens, or exposed credentials in a public GitHub issue.

Send a private report to **lnmput@gmail.com** with:

- A clear description of the problem
- The affected extension version
- Steps to reproduce
- The likely impact
- A minimal proof of concept, if appropriate

Remove unrelated personal data and do not access other users' accounts or content while investigating.

## Supported version

Security fixes are applied to the latest version available from the [Chrome Web Store](https://chromewebstore.google.com/detail/chatgpt-ai-chat-backup-ma/oedpeddiacomhhfieanenlmdghkolgng). Update before reporting an issue that may already be resolved.

## Public support questions

For normal export, Notion, Markdown, or Obsidian problems, use the public [support process](SUPPORT.md).
